# AR Tsumiki

AR Tsumikiは、現実空間で仮想の積み木（ブロック）を操作できる、three.jsベースの拡張現実（AR）アプリケーションです。

## デモ
デモはこちらで公開されています: https://code4fukui.github.io/ar-tsumiki/

## 特徴
- モバイルデバイスのカメラを使ったARでの操作をサポート
- さまざまな形状や色のブロックを提供
- 現実空間内でブロックを移動、回転、スナップ（吸着）させることが可能
- パズルのような形状の「jig」モードを搭載

## 動作環境
本アプリケーションを利用するには、対応するモバイルデバイス上で、最新のGoogle ChromeやMozilla Firefoxなど、WebXRをサポートするモダンWebブラウザが必要です。

## 使い方
AR Tsumikiを使用するには、モバイルデバイスの対応Webブラウザでデモのリンクを開いてください。アプリケーションからカメラへのアクセス許可を求められるので、許可すると、現実空間で仮想のブロックを操作できるようになります。
